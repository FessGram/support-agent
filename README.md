# net-monitor

Лёгкий мониторинг доступности серверов и сетевого оборудования с алертами
в Telegram. Написан на Python, без базы данных и зависимостей от SaaS —
конфиг в одном JSON-файле.

## Возможности

- Проверка сервисов по TCP-портам (RDP, SMB, Winbox, HTTPS и др.)
- Автоматическое использование ICMP-ping, если порт не указан
- Алерт в Telegram **только при смене состояния** (up↔down) — без спама
- Стартовое сообщение со статусом всех хостов при запуске
- Логирование проверок и причин ошибок в файл

Скриншот:
![Пример алерта](image.png)
## Как работает

Скрипт циклически опрашивает хосты из `config.json`по тайм-ауту:

- если задан порт — устанавливает TCP-соединение (`socket`);
- если порт пустой — выполняет `ping` и проверяет наличие TTL в ответе.

Состояние каждого хоста хранится в памяти. Сообщение в Telegram
отправляется только при изменении состояния с предыдущей проверки.

## Быстрый старт

Требования: Python 3.8+

```bash
git clone https://github.com/FessGram/net-monitor.git
cd net-monitor
pip install requests

copy config.example.json config.json
# вписать в config.json токен бота telegram, chat_id и свои хосты

python monitor.py
```

## Настройка

Создать бота через @BotFather → получить токен
Узнать свой chat_id через https://api.telegram.org/bot<ТОКЕН>/getUpdates
Заполнить config.json:

```json
{
    "telegram_token": "<токен из BotFather>",
    "telegram_chat_id": "<ваш chat_id>",
    "hosts": [
        { "name": "Router", "host": "192.168.1.1", "port": 8291 },
        { "name": "Workstation", "host": "PC-001", "port": "" }
    ]
}
```

Порт можно оставить пустым ("") — тогда хост проверяется ping'ом.
Подобрать открытый порт в Windows:

```bash
Test-NetConnection <host> -Port 3389
```

## Важно про безопасность

config.json содержит секреты и не хранится в репозитории (см. .gitignore).
В репозитории лежит только шаблон config.example.json. Если токен попал
в открытый доступ — отозвать через BotFather (Revoke token).
